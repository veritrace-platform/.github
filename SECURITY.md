# Security Policy

## Reporting a vulnerability

Please do not open public issues for security problems. Report them privately through
**GitHub Security Advisories**: on the affected repository, go to *Security → Report a vulnerability*.

Include the affected repository and version (or commit), the steps to reproduce, and the impact you
observed. We acknowledge reports within 5 business days.

## Scope

All repositories in the `veritrace-platform` organization, including infrastructure configuration and
smart contracts deployed to public testnets.
